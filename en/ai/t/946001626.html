Applies to: all engines; all production periods

One of the front door windows (driver's side or passenger side) only works manually; when the control button is pressed for longer than 300 ms and then released, the window does not open/close automatically, but stops.

Applies to: all engines; all production periods

The driver's door node control unit is programmed to move the driver side window up and down manually and automatically while the passenger side window can only be wound up manually but wound down manually or automatically. The specific control unit activates the manual function if the control button is pressed for beween 60 and 300 ms (briefly), whilst the automatic function is activated if the control button is pressed for longer than 300 ms (long period).
