Removing

Refitting

1. Release the door housing seal in the area of the front pillar cover.

2. Release the inner retainers using the special tool.

Tool

Description

Function

Validity

Knife

Retainer removal

Applies to: all engines; all production periods

1. Undo the rod retaining bolt

2. Keep the front pillar trim.

Applies to: all engines; all production periods

Refitting

Removing

- Check that the front pillar cover is not damaged.

- Fit the front pillar trim in place.

- Tighten the rod retaining bolt

- Attach the inner retainers for the trim.

- Fit the door housing seal.

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods; only with equipment: Spider
