Applies to: all engines; all production periods

1

CLUTCH SWITCH CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the clutch pedal switch is working properly

Move on to Step 2

No continuity

Replace the clutch pedal switch

Op. 1056F78 SWITCH ON CLUTCH PEDAL - R.R. (PETROL ENGINES)

(for petrol engines).

2

ENGINE MANAGEMENT CONTROL UNIT CONNECTIONS CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the ignition key in the ON position and the clutch pedal pressed, check for an earth signal at the engine management control unit coming from the clutch switch:

See E5060 CRUISE CONTROL

Move on to Step 3

Signal interrupted

Repair the connections:

See E5060 CRUISE CONTROL

3

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present by carrying out

See Test 5580AE CRUISE CONTROL OPERATION ROAD TEST

End of diagnosis

The fault persists: engine control unit defective

Replace the engine management control unit

Op. 1056F82 CONTROL UNIT (ONE) FOR INJECTION IGNITION SYSTEM - R.R.
