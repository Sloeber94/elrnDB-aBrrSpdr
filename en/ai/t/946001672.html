P010 CENTRAL LOCKING NOT WORKING

Applies to: all engines; all production periods

When the central locking is operated via the driver's door using the mechanical key and/or from the inside, via the locking/unlocking buttons, the central locking system does not work.

Applies to: all engines; all production periods

The door locking/unlocking command reaches the Body Computer Node via the CAN. The body computer node sends the signal received to the rear door and boot locks.

Applies to: all engines; all production periods
