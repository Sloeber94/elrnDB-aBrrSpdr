The problem disappears if I release the accelerator pedal when changing, it seems as though the clutch slips and there is sometimes a burning smell

Applies to: engines: 2.2 JTS; all production periods

Test results

1

ERRORS IN AUTOMATED GEARBOX CONTROL UNIT CHECK

All OK

Problems encountered

Operation

Connect the Examiner diagnostic equipment and check that there are no errors in the automated gearbox control unit. More specifically:

- CAN error (Engine Management Node - Automated Gearbox Node communication)

Move on to Step 3

CAN error (automated gearbox Node communication - engine management control unit

Move on to Step 2

2

CHECK ON CAN ERRORS

All OK

Problems encountered

Operation

Select CAN information on the Examiner and check for the presence of any faulty control units

Check for possible "No accelerator pedal information"

Check the state of the connections and the continuity of the line wiring, in particular at the control units signalled as faulty.

End of diagnosis

Fault at the connections

Restore/replace the wiring

See E7051 ROBOTIZED GEARBOX

One of the control units does not dialogue.

Restore/replace the control unit involved

3

CARRY OUT AUTO CALIBRATION AND CHECK CLUTCH PARAMETERS USING THE EXAMINER

All OK

Problems encountered

Operation

Keeping the diagnostic equipment connected, enter Active Diagnosis and then Configurations/Procedures and set the clutch parameters in Clutch autocalibration enablement

Check the Calculation of the clutch index parameter in Select

Move on to Step 4

The outcome of the autocalibration procedure is not successful

Restore the connections between the clutch position sensor and the gearbox control unit

The Clutch index parameter has a high positive value

Move on to Step 4

4

CHECK WITH ROAD TEST

All OK

Problems encountered

Operation

Carry out a road test taking care to make the maximum number of gear changes possible using all the available gears (at different engine speeds and loads), making sure that the fault has disappeared.

End of diagnosis

The fault persists.

Move on to Step 5

5

CLUTCH PLATE CHECK

All OK

Problems encountered

Operation

Check that the clutch plate is not worn and that the surface is not fouled by oil.

End of diagnosis

The clutch plate is worn/does not conform

Replace the clutch kit
