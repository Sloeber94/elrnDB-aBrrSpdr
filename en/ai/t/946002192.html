ATTENTION

WARNINGS

This vehicle is equipped with a starting system known as Smart-Key, whereby the traditional ignition key has been replaced with an electronic key "T.E.G.", (Transmitter for Entry and Go), combined with an electronic key reader and TEG Reader radio frequency receiver.

When the battery is disconnected, the Steering Lock Node remains in the same condition (released or locked) as previously. Whenever it is necessary to turn the steering wheel with the battery disconnected during workshop operations, leave the TEG inserted when disconnecting the battery: the steering will thereby remain unlocked and free to turn.

Each time the battery is disconnected the vehicle loses some electrical parameters; therefore when the battery is reconnected the vehicle electrical system initialization procedure should be carried out following the instructions below.

INITIALIZATION PROCEDURE FOR DOOR NODES (BRERA)

Following a power supply failure to the control units (for example, battery disconnection) the system must be initialized once again, following the instructions below and working with the ignition key ON (TEG inserted) and the doors and windows closed.

- completely open the driver's door window, keeping the operating button pressed for at least 3 seconds after the (lower) end of travel position

- completely close the driver's door window, keeping the operating button pressed for at least 3 seconds after the (upper) end of travel position

- carry out the same operations for the passenger window

- make sure that the initialization is correct by checking that the windows work properly in automatic mode.

INITIALIZATION PROCEDURE FOR DOOR NODES (SPIDER)

- Connect the battery.

- Close the boot lid.

- Insert the TEG.

- Close the hood using the electric control (if not available, use the emergency system).

- Get into the vehicle and close the doors.

- Close the windows in the doors, using the buttons and keep the buttons pressed for at least 3 seconds after the end of travel closed position has been reached. Release the buttons.

- Open the windows in the doors, using the buttons and keep the buttons pressed for at least 3 seconds after the end of travel open position has been reached. Release the buttons.

- Close the windows in the doors until the end of travel closed position has been reached. Release the buttons.

- The initialization procedure is over; to check that the initialization has taken place, carry out the check described below.

- Place the window for one of the doors in an intermediate open position; open the same door and check that the window does not descend during the initial opening. If the window does lower then the vehicle has not been initialized and the process must be carried out/repeated.
