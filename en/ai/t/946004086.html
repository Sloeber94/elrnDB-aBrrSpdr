Removing

Refitting

- Prepare the hood for the operation.

Op. 0010T79 HOOD HYDRAULIC SYSTEM - DISCHARGE AND RESTORE PRESSURE

1. Using the electric control, place the hood housing cover (1a) in a fully raised position and the side cover (flap) (1b) in a lowered position (as illustrated).

2. Undo the striker retaining nuts.

3. Remove the striker (3a); keep the shims (3b), if present.

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods

Refitting

Removing

- Check that the striker is not damaged.

1. Position the striker (1a) and the shims (1b).

2. Screw in the striker fixing nuts without tightening them. The position of the striker can be adjusted: the arrows indicate the possible movements for the striker; the variation of the shims (1b) adjusts the distance from the cover.

- If discharged, restore the hood hydraulic system pressure.

Op. 7030H03 HOOD MANUAL OPENING FOLLOWING DEACTIVATION OF HYDRAULIC SYSTEM - CARRY OUT PROCEDURE

- Using the electric control, carefully place the hood housing cover in the closed position to centre the striker on the lock. Also check that the profile of the hood housing cover is correct in relation to the bodywork.

- Open the hood housing cover again and, if necessary, adjust the position of the striker further.

3. When the striker is in the correct position, tighten the nuts.

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods

- Using the electric control, move the hood housing cover and check that it is working properly.
