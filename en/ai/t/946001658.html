Test results

1

BOWDEN CABLE MOUNTING CHECK

All OK

Problems encountered

Operation

Check that the bowden cable for the guide memory is correctly mounted (cable+idler+spring)

Move on to Step 2

Control cable from regulator/idler spring/outer casing retaining bracket detached, broken

Reattach the cable or replace the control unit

Op. 7045A88 FRONT SEAT BACKREST FOLDING DEVICE WITH FLEXIBLE CABLES, LEFT OR RIGHT - R.R.

2

MEMORY UNIT CHECK

All OK

Problems encountered

Operation

Check the condition of the memory unit checking, in particular, for the presence of foreign elements between the memory guide mechanisms or distortion/breaking of the memory plate tooth

Move on to Step 3

1. Foreign elements present between the memory guide mechanisms

2. Memory plate tooth and/or kinematic components distorted/broken

1. Release the mechanisms from the elements in between and lubricate the connecting rods/hinges/control shaft

2. Replace the memory guide

Op. 7045A64 FRONT SLIDING SEAT POSITION MECHANICAL MEMORY CONTROL CABLE . (ONE), LEFT OR RIGHT - R.R.

3

CORRECT SEAT FASTENING CHECK

All OK

Problems encountered

Operation

Check the following, in order:

- the application of the correct seat tightening cycle to the vehicle floor;

- the correct flatness of the seat fastening bodyshell bracket;

- the correct attachment of the mounting to the element control aerial;

- the presence of distortions to the element;

- the travel of the stem release control

End of diagnosis

1. Incorrect fitting of seat to the floor

2. Flatness not correct

3. Incorrect attachment of the mounting to the element control aerial

4. Presence of distortions to the element

4. Incomplete travel of the stem release control

1. Fit the seat correctly on the floor

2. Place a correct size shim between the guide and the bracket

3. Replace the guide release mounting

3. Reattach the mounting correctly in position

4. Replace the guide
