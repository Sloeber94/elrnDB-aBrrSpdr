Applies to: all engines; all production periods

When the door lock is operated using the remote control, the central locking system does not work.

Applies to: all engines; all production periods

The door locking/unlocking command reaches the Body Computer Node via the CAN. The body computer node sends the signal received to the rear door and boot locks.

Applies to: all engines; all production periods

0

PRELIMINARY CHECK

All OK

Problems encountered

Operation

Check that the door locking/unlocking system is working properly using the interior buttons

Check that the remote control battery is not run down.

Move on to Step 1

System not working using the buttons

Move on to Step 1

Battery flat

Replace the battery

Problems encountered

Operation

Keeping the Examiner diagnostic equipment connected, check:

- no control units inactive;

- no faulty control units;

- no control units with faulty CAN line;

Continue following the instructions for the diagnostic equipment.

CHECK USING DIAGNOSTIC EQUIPMENT

Problems encountered

Operation

Using the Examiner diagnostic equipment, check that the learning of the change of status of the door locking/unlocking switch is correct by turning the key in the lock barrel

End of diagnosis

The door lock change of status has not been learnt.
