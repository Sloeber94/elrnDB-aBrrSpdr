P014 BOOT OPENING/CLOSING NOT WORKING

Applies to: all engines; all production periods

When the opening/closing of the luggage compartment is operated using the key, or the opening using the button in the control panel, the boot does not open and does not close

Applies to: all engines; all production periods

1

FUSE AND RELAY CHECK

All OK

Problems encountered

Operation

Check the condition of the fuses and relays

See E3045 BOOT AND FUEL FLAP OPENING

Move on to Step 2

Components faulty

Replace the component (in the case of a fuse, find out what caused it to blow)

2

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Check the boot lid opening/closure in active diagnosis

Move on to Step 6

The boot will not open/close

Move on to Step 3

3

ELECTRICAL CIRCUIT CHECK

All OK

Problems encountered

Operation

Check the electrical connection between the body computer node, driver's door node and boot lock

See E3045 BOOT AND FUEL FLAP OPENING

Move on to Step 4

Electrical connector on boot lock incorrectly connected

Connect the electrical connector to the boot lock correctly

Connections broken or not insulated

Restore the continuity/insulation of the electrical connection

See E3045 BOOT AND FUEL FLAP OPENING

4

ELECTRICAL SIGNAL CHECK

All OK

Problems encountered

Operation

Disconnect the electrical connector for the boot lid lock and check for the opening control signal

Move on to Step 5

Opening control signal missing

Move on to Step 7

5

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Check that the fault is no longer present.

End of diagnosis.

The fault persists.

Replace the boot lock motor

Op. 7015B70 TAILGATE LOCK MOTOR - R.R AND CHECK LOCK SUPPLY LINE

6

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Press the button in the dashboard and check the driver's door node to ensure that the status of the boot lid opening button alters while in parameter mode.

Move on to Step 8

There is no change in status

Move on to Step 7

7

ELECTRICAL CIRCUIT CHECK

All OK

Problems encountered

Operation

Check the electrical connection between the switch on the console and the driver's door node

See E3045 BOOT AND FUEL FLAP OPENING

Check that the switch is working properly

Move on to Step 8

Connections broken or not insulated

Restore the continuity/insulation of the electrical connection

See E3045 BOOT AND FUEL FLAP OPENING

Switch faulty

Replace the switch on the console

Op. 7015B81 TAILGATE OPENING CONTROL SWITCH - R.R.

8

REPLACE THE DRIVER'S DOOR NODE

All OK

Problems encountered

Operation

Replace the Driver's Door Node

Op. 5505A42 CONTROL UNIT (DIGITAL NETWORK NODE) IN DRIVER'S DOOR - R.R.

and check that the fault is no longer present.

End of diagnosis.

The fault persists.

Restore the driver's door node and replace the body computer

Op. 5505A32 BODY COMPUTER - R.R
