Description

The vehicle is equipped with a robotized electronically controlled manual gearbox.

The gearbox comprises a traditional manual transmission with a gear lever to which an electronically controlled eletrohydraulic device that automatically manages the clutch and the engagement of the gears has been added.

There are two system operating modes for the robotized gearbox:

  • SEMIAUTOMATIC mode (MANUAL): the driver engages the gears using the lever on the tunnel;
  • AUTOMATIC mode (DRIVE): the decision to change gear depending on the engine load is delegated to the electronic system.

there are two different operating logics for both operating modes (NORMAL/SPORT):

  • NORMAL standard strategy;
  • high performance SPORT logic that can be activated using a dedicated button located near the gear lever. When the button is activated the gearbox uses different maps for more aggressive gear changes and the engine also responds in a different way from the NORMAL strategy.

The control lever on the centre tunnel is the multistable floating type, in other words it has three stable and three unstable positions.

The three stable positions correspond to neutral N, reverse R and the centre TIP position located between the unstable UP (+) and DOWN (-) positions.

There are also two rocker levers on the steering wheel spokes through which it is possible to increase/decrease the gear irrespective of the speed if the gear lever is in the TIP position.

With the vehicle stationary, a gear can only be engaged from lever position N if the brake pedal is pressed; this function is known as SHIFT-LOCK and is produced by an electromagnet located under the gear lever.

Below a certain speed (10 Km/h) the control unit leaves the shif-lock coil released to allow a shift from N to a gear without having to press the brake pedal.

At every key-on the system always selects the operating mode memorized the last time it was switched off.

The electronic control unit for the robotized gearbox converses with the engine management control unit via the CAN and two dedicated lines, one for the engine rpm signal, one for the fault diagnosis.

The control unit operates an electro-hydraulic unit located on the gearbox, via a special electric pump, according to a complex operating logic.

The autodiagnosis of the control unit indicates the source of these faults through messages and by turning on a dedicated warning light in the instrument panel. The control unit also sends the instrument panel information concerning the gear engaged which is shown in the display.

The power supply lines for the control unit and the various system components (sensors and actuators) are protected by three fuses located in the junction unit under the dashboard.
