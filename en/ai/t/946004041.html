The hood does not open / close when the button is pressed.

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods; only with equipment: Spider

Test results

1

PRESSURE RELIEF VALVE CHECK

All OK

Problems encountered

Operation

Open the hood manually

Op. 7030H03 HOOD MANUAL OPENING FOLLOWING DEACTIVATION OF HYDRAULIC SYSTEM - CARRY OUT PROCEDURE

Check whether the hydraulic unit motor turns when the hood activating button is pressed; if it does, check that the lever which operates the hydraulic system emergency release valve has not been pulled by mistake by carrying out the specific test

See T CHECK ON HYDRAULIC SYSTEM EMERGENCY RELEASE VALVE

Move on to Step 2

Valve in exhaust position

Return the lever that operates the hydraulic system emergency release valve to the correct position.

2

FLUID LEVEL CHECK

All OK

Problems encountered

Operation

Check the level of the oil in the reservoir and check for leaks from the reservoir/solenoid valve assembly.

Move on to Step 3

Oil level not correct.

Restore correct oil level
