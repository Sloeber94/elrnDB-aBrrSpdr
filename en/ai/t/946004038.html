Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods; only with equipment: Spider

While driving with the hood closed (in coupé models), noise can be heard coming from the hood area.

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods; only with equipment: Spider

Test results

0

PRELIMINARY CHECKS

All OK

Problems encountered

Operation

Check whether the noise only occurs with the hood closed.

Move on to Step 1

The noise is heard with the hood open.

Proceed as instructed

See table S089 HOOD NOISY - WITH HOOD OPEN

1

FLAP NOISE CHECK

All OK

Problems encountered

Operation

Check for flap creaking

Move on to Step 2

Flap creaking present

Lubricate the shaft with oil and check if the fault recurs; if it persists replace the motors

Op. 7210E47 HOOD HOUSING COMPARTMENT SIDE COVER - R.R.

2

HOOD COVER FRAME BUFFERS CHECK

All OK

Problems encountered

Operation

Check that the two rubber buffers fitted at the bottom of the hood cover frame for containing jolts whilst driving are present and are not faulty.

Move on to Step 3

Two rubber buffers not fitted / not intact.

Refit the two buffers correctly

3

FRONT LOCK ACTUATOR PIPES CHECK

All OK

Problems encountered

Operation

Check that the hydraulic pipes on the left side of the hood for the front lock hydraulic actuator are correctly fastened.

End of diagnosis

Hydraulic pipes not correctly fastened.

Restore the correct fastening of the front lock duplex pipes

Op. 7030H80 DUPLEX PIPE FROM CONTROL UNIT TO HOOD FRONT LOCK HYDRAULIC ACTUATOR (HOOD EXTENSION/CONTRACTION MOVEMENT)
