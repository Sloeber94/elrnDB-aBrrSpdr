P015 LUGGAGE COMPARTMENT DOES NOT OPEN WITH REMOTE CONTROL

Applies to: all engines; all production periods

The boot lid does not open when the remote control is operated.

Applies to: all engines; all production periods

The opening command for the boot lid is received by the body computer node; the body computer node unlocks the boot lid lock and releases it gently, disabling the alarm (if fitted).

Applies to: all engines; all production periods

With the "central locking switched off", the boot lid opens activating the electric handle located on the actual boot lid.

Applies to: all engines; all production periods

In "indepedent boot" mode, the opening of the boot lid is implemented using the remote control or by means of the mechanical key pawl.

Applies to: all engines; all production periods
