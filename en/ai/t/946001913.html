Removing

Refitting

The procedure for the intake side sensor is described below, the operations for the exhaust side sensor are the same.

- Make sure that the ignition key is in the OFF position, then disconnect the battery terminal (-).

1. Disconnect the electrical connection for the cam angle sensor.

Description

Connector

1

Inlet side timing sensor

See K106 INTAKE SIDE TIMING SENSOR

2. Undo the bolts (2a) and remove the cam angle sensor (2b).

Applies to: engines: 2.2 JTS; all production periods

Refitting

Removing

- Position the cam angle sensor in its housing and secure it using the bolt.

- Connect the electrical connection for the cam angle sensor.

- Connect the negative battery terminal.
