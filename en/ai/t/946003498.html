The diagnostic equipment signals: Error P2135 (Accelerator pedal potentiometer (plausibiity).

Applies to: engines: 2.4 JTD 20v; all production periods

This error is detected if, with fault code P0641 and/or P0651 not recognized, the control unit detects a general error for hte pedal position sensor. As a result, the accelerator pedal does not work.

Applies to: engines: 2.4 JTD 20v; all production periods
