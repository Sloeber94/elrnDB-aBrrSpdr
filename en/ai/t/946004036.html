Q007 THE HOOD DOES NOT WORK

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods; only with equipment: Spider

The hood system is governed by a control unit which converses with the vehicle B CAN which receives signals from a series of sensors and controls the various actuators for the correct implementation of the opening and closing cycles.

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods; only with equipment: Spider

If the hood opening/closing cycles continue for between 12 and 15 minutes, the solenoid valve control system goes into protective mode and prevents regular operation (the hood can only be closed) until the normal operating temperature is reached.

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods; only with equipment: Spider
