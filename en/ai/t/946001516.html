Applies to: all engines; all production periods

When the side light switch is operated, the side light/number plate lights do not operate;

Applies to: all engines; all production periods

The activation signal for the side lights and the no. plate lights is supplied directly by the Body Computer Node.

Applies to: all engines; all production periods

The lights can be activated using the following controls:

1. EXTERIOR LIGHT CONTROL (on stalk) C.L.E.

- Side lights

2. PARKING LIGHT CONTROL ("PARK" key)

- Parking lights

3. COMMAND FROM DUSK SENSOR

4. FOLLOW ME HOME COMMAND FROM STALK

Applies to: all engines; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Connect the Examiner diagnostic equipment to the diagnostic socket on the Body Computer Node and and check for errors.

Move on to Step 2

Presence of errors

Continue following the instructions for the diagnostic equipment

2

ELECTRICAL SYSTEM CHECK

All OK

Problems encountered

Operation

- Check the continuity and the insulation of the wiring between the Exterior Lights Control and the Body Computer Node

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

- Check the stalk connection to earth

Move on to Step 3

Wiring between stalk and Body Computer interrupted

Restore the correct electrical connection

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

Lighting stalk earth reference interrupted

Restore the correct electrical connection

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

3

EXTERIOR LIGHTS CONTROL CHECK

All OK

Problems encountered

Operation

Check the control on the stalk is intact

See E2010 SIDE LIGHTS / NO. PLATE LIGHTS

Also check the operation of the body computer

End of diagnosis

Stalk switch not working

Replace the steering column switch unit

Op. 5550A10 STALK UNIT ASSEMBLY - R+R

Body Computer defective.

Replace body computer

Op. 5505A32 BODY COMPUTER - R.R
