The fog lights are not working;

Applies to: all engines; all production periods

The fog lights are controlled by the Body Computer Node via a relay located in the Engine Compartment Control Unit.

Applies to: all engines; all production periods

1

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Connect the Examiner diagnostic equipment to the diagnostic socket and check the following at the Body Computer Node

Move on to Step 2

Errors present in the Body Computer

Continue following the instructions for the diagnostic equipment.

2

FOG LIGHTS RELAY CHECK

All OK

Problems encountered

Operation

Check the condition of the fog lights relay

Move on to Step 3

Relay defective

Replace the relay

3

CHECK ON OPERATION OF ENGINE COMPARTMENT JUNCTION UNIT FUSE

All OK

Problems encountered

Operation

Check that fog lamp fuse in the engine compartment junction unit is working properly

Move on to Step 4

Fuses blown

Replace the fuses

4

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Keeping the diagnostic equipment connected, check in active diagnosis that the fog lights are working properly

Move on to Step 7

Main beam headlamps not working

Move on to Step 5

5

BODY COMPUTER CONNECTION CHECK

All OK

Problems encountered

Operation

Check for deformed terminals or connections not present on the Body Computer

Move on to Step 6

Missing connections/pins bent

Renew the correct connections

6

CHECK ON OPERATION OF BULBS

All OK

Problems encountered

Operation

Check that the fog lights are working properly

Move on to Step 8

Filament in one of the bulbs broken

Replace bulb

Op. 5540D14 L/H OR R/H FOG LIGHT BULB (ONE) - R+R

7

FOG LIGHT ACTIVATION SWITCH CHECK

All OK

Problems encountered

Operation

Check that the foglamp switch is operating correctly

Move on to Step 8

Fault in foglamp activation/deactivation switch

Replace the control panel

Op. 7040A56 SWITCH UNIT IN DASHBOARD - R.R.

8

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Replace Body Computer

Op. 5505A32 BODY COMPUTER - R.R
