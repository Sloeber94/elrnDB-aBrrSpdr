Removing

Refitting

- Position the vehicle on a lift.

- Draw off the power assisted steering fluid from the reservoir using a suitable syringe.

1. Disconnect the rapid connector for the intermediate return pipe from the power steering box to the heat exchanger, heat exchanger side.

Applies to: engines: 2.2 JTS; all production periods

1. Undo the bolt (1a) and the nut (1b) securing the intermediate return pipe between the power assisted steering box and the heat exchanger to the front suspension frame.

2. Disconnect the rapid connector for the intermediate return pipe from the power steering box to the heat exchanger, power assisted steering box return pipe side.

3. Remove the intermediate return pipe between the power assisted steering box and the heat exchanger.

Applies to: engines: 2.2 JTS; all production periods

Refitting

Removing

- Refit the intermediate return pipe from the power steering box to heat exchanger.

- Connect the rapid connector for the intermediate return pipe from the power steering box to the heat exchanger, power assisted steering box return pipe side.

- Tighten the bolt and the nut securing the intermediate return pipe between the power assisted steering box and the heat exchanger to the front suspension frame.

- Connect the rapid connector for the intermediate return pipe from the power steering box to the heat exchanger, heat exchanger side.
