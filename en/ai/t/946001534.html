I081 HEADLAMP ALIGNMENT ADJUSTER (ONE) RH OR LH NOT WORKING

Applies to: all engines; all production periods; only with equipment: Gas discharge headlamps

One headlamp comes on normally but the vertical adjustment is not carried out

Applies to: all engines; all production periods; only with equipment: Gas discharge headlamps

if the control unit for the master headlamp is being replaced, delete the errors in the memory using the Examiner and calibrate the system

Applies to: all engines; all production periods; only with equipment: Gas discharge headlamps

Test results

1

CHECK USING DIAGNOSTIC EQUIPMENT

All OK

Problems encountered

Operation

Check the master headlamp control unit (left side) and check for errors. Connect to the slave headlamp control unit (right side) and check for errors.

End of diagnosis

Presence of error B1040 detected - Headlamp alignment corrector

Move on to Step 2

2

CHECK ON CONNECTION INSIDE THE HEADLAMP

All OK

Problems encountered

Operation

Check that the connection for the headlamp vertical adjustment motor is correctly connected by carrying out the test

See Test 5540BK CHECK THE CONTINUITY OF THE LOW BEAM WIRING INSIDE THE HEADLAMP

Move on to Step 3

3

MOTOR OPERATION CHECK

All OK

Problems encountered

Operation

Replace the left headlamp

Op. 5540B81 LEFT GAS DISCHARGE LIGHT CLUSTER - R.R.

or right headlamp

Op. 5540B82 RIGHT GAS DISCHARGE LIGHT CLUSTER - R.R.

(the broken one) and check that the motor is working properly

End of diagnosis

Right headlamp alignment corrector not working

Move on to Step 4

Left headlamp alignment corrector not working

Move on to Step 4

4

CHECK ON CORRECT OPERATION

All OK

Problems encountered

Operation

Refit the headlamp replaced previously and replace the ballast control unit for the headlamp that is faulty

Op. 5540B40 CONTROL UNIT IN LEFT GAS DISCHARGE LIGHT CLUSTER - R.R.

and/or

Op. 5540B41 CONTROL UNIT IN RIGHT GAS DISCHARGE LIGHT CLUSTER - R.R.

End of diagnosis

The fault persists

Contact technical service for further information on the problem
