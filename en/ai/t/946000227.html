Applies to: all engines; all production periods; only with equipment: Blue&amp;Me

DESCRIPTION

The Blue&Me system allows mobile phones to be used safely inside the vehicle.

Includes:

- Bluetooth receiver;

- voice recognition integrated unit including microphone

- integral Text to Speech unit.

- USB interface for Media Player.

The control unit is also connected to radio controls on the steering wheel (two special keys for this function are provided in addition to the radio control keys).

The entire operation of the system is also managed by voice commands, picked up by the microphone near the front courtesy light

The alphanumeric display used is that of the control panel.
