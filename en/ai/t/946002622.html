Applies to: all engines; all production periods

Removing

Refitting

- Open the tailgate.

1. Undo the bolts.

2. Undo the bolts (2a) and keep the attachment rings (2b).

3. Remove the moulding (3a) releasing the inner retainers (3b) using the special tool.

Tool

Description

Function

Validity

1823015000

Knife

Retainer removal

Applies to: all engines; all production periods

Refitting

Removing

- Check that the moulding is not damaged.

- Position the attachment rings and tighten the bolts.

- Tighten the bolts.

- Close the tailgate.

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods; only with equipment: Spider

Removing

Refitting

- Open the boot lid.

- Lift up the floor covering.

1. Undo the bolts and remove the mounting rings.

2. Undo the bolts.

3. Remove the moulding.

Applies to: engines: 2.2 JTS, 3.2 JTS; all production periods; only with equipment: Spider

Refitting

Removing

- Check that the moulding is not damaged.

- Position the moulding and tighten the fixing bolts.

- Position the mounting rings and tighten the bolts.

- Lower the floor covering.

- Close the boot lid.
