M003 ONE OF THE ELECTRIC FRONT WINDOWS IS NOT WORKING

Applies to: all engines; all production periods

With the ignition in the ON position, when the button is operated, one of the front electric windows is not working at all.

Applies to: all engines; all production periods

Each of the front windows is controlled by a switch on the door panel; the driver's door switch, in particular, can also control the movement of the front passenger side window.

Applies to: all engines; all production periods

The window system features a short drop function to ensure complete closure of the door lacking an upper reinforcement. For more information, seeSee descriptions 7005 PASSENGER COMPARTMENT FRONT SIDE DOORS

Applies to: all engines; all production periods
