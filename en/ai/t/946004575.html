STEP

CHECK TO BE PERFORMED

REMEDIAL ACTION IF THE CHECK IS NOT OK

1

Checking the gear lever

Press the Start/Stop button

Connect the Examiner diagnostic equipment and select the "LEVER STATUS" display.

Carry out all the possible selections using the gear lever checking that the change is status on the Examiner is correct; the list of selections to be made is as follows:

- Lever in neutral (N) (stable position)

- Lever in reverse (R) (stable position)

- Lever released (stable position)

- With the lever in this position (check the status using the Examiner) it is possible to access the following selections:

- Lever in Up position (+) (forwards) (unstable position)

- Lever in Down position (-) (forwards) (unstable position)

- Select Auto mode.

Move on to Step 2

2

Checking selector lever operation

Check the voltages at the respective gearbox control unit pins against the values in the attached table for each selector lever position

Move on to Step 3

Replace selector lever

Op. 2127A12 HAND LEVER FOR MANUAL GEARBOX WITH HYDRAULIC SELECTION - R.R.

If ok, restore wiring

Replace the robotized gearbox control unit

Op. 2127E10 HYDRAULIC SPEED SELECTION SYSTEM CONTROL UNIT - R.R.

3

Check the wiring

Check wiring continuity between the robotized gearbox control control unit and the selector lever.

Move on to Step 4.

Restore the continuity/insulation for the wiring

See E7051 ROBOTIZED GEARBOX

if OK, replace the robotized gearbox control unit

Op. 2127E10 HYDRAULIC SPEED SELECTION SYSTEM CONTROL UNIT - R.R.

4

Check on +15 power supply

Press the Start/Stop button

Check that the voltage between selector lever pin 6 and earth is around 12 Volts

See E7051 ROBOTIZED GEARBOX

Move on to Step 5.

Replace the 15A fuse F24 after having identified the cause of malfunction.

Restore correct power supply

See E7051 ROBOTIZED GEARBOX

Restore the continuity/insulation for the wiring

See E7051 ROBOTIZED GEARBOX

5

Checking the gear lever earth

Press the Start/Stop button

Check that the voltage between pins 1 and 6 of the gear lever is around 12 Volt

See E7051 ROBOTIZED GEARBOX

Restore the correct continuity for the wiring.

Replace the robotized gearbox control unit

Op. 2127E10 HYDRAULIC SPEED SELECTION SYSTEM CONTROL UNIT - R.R.
